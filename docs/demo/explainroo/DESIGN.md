# AgentLint video direction

Warm editorial typography with one clear focal point at a time. The message
is developer autonomy with project rules enforced during ordinary coding. The
high-end-visual-design skill supplies typography and motion principles;
the user's request for sober simplicity takes priority over decorative UI.

- Canvas: warm ivory `#f5f2eb`; text: charcoal green `#1d3027`.
- Accent: forest `#2e654c`; coral denotes a blocked action or risky literal.
- Typography: Geist for the interface; Instrument Serif italic for a short
  headline accent; Geist Mono only for actual commands and rule identifiers.
- Layout: a small wordmark, a centered headline or a single 1560px code
  panel, 180px panel margins, and captions in an unboxed area below 876px.
- Panels: matching 22px outer / 20px inner radii and a 2px warm inset. No
  shadows, nested callout boxes, terminal window chrome, or status pills.
- Motion: restrained 22px upward reveals with quartic easing, aligned to
  narration cues. Only the content needed for the current idea appears.
  Clean chapter cuts keep outgoing and incoming text from crossfading together.

The opening names AgentLint and explains that it adds guardrails to coding
agents by checking file changes and shell commands. A second scene names
the problem: credential exposure and destructive commands. Then a masked
credential assignment is blocked before the file changes. Its corrected
environment-variable version is allowed, followed by a permitted test invocation.
These are sequential states of one story; do not place before/after panels
side by side. A short feature summary covers local checks, configurable packs,
CI, and supported agents. Finish with setup and the repository URL. There are
no infrastructure or severity slides, feature cards, chapter labels, footer
disclaimers, or watermark. Keep fixture
disclosure and captured evidence in the docs, and never imply that tests passed.

Text is measured before drawing and overlong labels stop the render. Labels
also remain visible to ExplainRoo's layout checker. Important text is at least
36px in the 1920px frame (16px in an 854px player). Inspect both the finished
layouts and the moving frames; the checker cannot detect a shape obscuring text.

The narration, code examples, and hook decisions remain grounded in the
captured AgentLint output. The video has no third-party watermark.
