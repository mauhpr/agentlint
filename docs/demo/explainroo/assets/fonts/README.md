# Fonts used by the video

- `Geist.ttf`: [Geist variable font](https://github.com/google/fonts/tree/main/ofl/geist),
  downloaded from Google Fonts on 2026-10-12. Git blob `f63f0afc6390323715972b6645115485f37cc9f4`.
- `GeistMono.ttf`: [Geist Mono variable font](https://github.com/google/fonts/tree/main/ofl/geistmono),
  downloaded from Google Fonts on 2026-10-12. Git blob `173867dce0580ea751e4b9c558740d34f20ce549`.

Both are redistributed under the SIL Open Font License in `Geist-OFL.txt`.
The fonts are bundled so renders do not depend on web font availability.

`InstrumentSerif-Italic.woff2` comes from the pinned ExplainRoo renderer's
bundled fonts. Its SIL Open Font License is in `InstrumentSerif-OFL.txt`.
